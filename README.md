# RSPLMainInstallerSetup

Full setup of the RSPL Main Installer: the tunnel agent service and the web services, for a new or an existing PC.

Latest version: https://github.com/Retailware/RSPLMainInstallerSetup/releases/latest/download/RSPLTunnelServiceSetup.exe

The agent's automatic updates are published separately, as service-only setups, in
[RSPLTunnelAgentServiceSetup](https://github.com/Retailware/RSPLTunnelAgentServiceSetup). This full setup is never an automatic update.
